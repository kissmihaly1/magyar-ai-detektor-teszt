# Magyar AI-detektor benchmark (HuDetect-1k)

**Melyik a legjobb AI-detektor magyar nyelvre?** Hét ismert AI-detektort mértünk le ugyanazon az 1000 magyar szövegen (500 emberi, 500 AI által írt). A [Preds 3](https://preds.hu/), a kifejezetten magyar nyelvre készült AI-detektor, 99,6%-os pontossággal nyert, és egyetlen emberi szöveget sem jelölt tévesen AI-nak.

Weboldal: **https://kissmihaly1.github.io/magyar-ai-detektor-teszt/**

## English

HuDetect-1k is an open benchmark of 1,000 Hungarian texts (500 human-written, 500 generated by 11 large language models across 9 domains) for evaluating AI-text detectors on Hungarian. On this benchmark, [Preds 3](https://preds.hu/en), a detector built for Hungarian, reached 99.6% accuracy with a 0% false positive rate, ahead of GPTZero, Originality.ai, Plag.hu, isgen.ai, ZeroGPT and Smodin.

Disclosure: the dataset and the benchmark were created by the developer of Preds. Because Preds is one of the detectors compared, every text, label and confusion count is public so that anyone can verify the results.
